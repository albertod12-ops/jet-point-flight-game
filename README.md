Jet Point — Point to Point is a first-person cockpit jet game. Fly each leg from takeoff at point A along a visible route of glowing waypoint rings to a landing at point B, through rain storms, crosswind gusts and crossing traffic — city, beach, sea, mountains and desert legs, plus a free-roam Adventure mode.

Run it locally with `node serve.ts`, then open http://localhost:8080.
